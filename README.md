# LumenWall · 深空动态媒体墙

> 让每一面屏幕，都成为流动的艺术装置。

LumenWall 是一款面向展厅、指挥中心与客厅屏保场景的全屏动态媒体墙引擎。不规则无缝拼贴、电影级切换动效、图影混排轮播、时空氛围联动 —— 开箱即用，7×24 小时长稳运行。

---

## ✨ 核心亮点

### 🖼 不规则无缝拼贴
网格预设覆盖 `2×2` 至 `5×5`，通过智能合并单元格（横图 2×1 / 竖图 1×2 / 大图 2×2）打破呆板的整齐感，零间距铺满整个视口。

### 🎬 图影混排 · 视频原生融入
- 图片与视频共用一套拼贴引擎，视频自动分配大格子，静默融入照片墙轮播
- **并发播放协调器**：同一时刻仅解码 2 路视频，其余定格首帧，资源占用可控
- **全屏沉浸播放器**：点击任意视频格子弹出影院级播放界面——进度、静音、时间轴一应俱全
- **卡顿自愈**：缓冲停滞 6 秒自动切换下一条，墙面永不停摆

### 🌀 九种切换动效
3D 双轴翻转 · 盒子翻转 · 缩放淡入 · 交叉溶解 · 滑动 · 马赛克 · **百叶窗** · **圆形展开**，每次切换随机编排，配合 Ken Burns 常驻运镜，画面始终"活着"。

### 🌗 时空氛围引擎
按时段（晨昏昼夜）、天气（雨雪自动切换冷调）、节日（内置公历节日色板）三级联动，背景渐变、强调色与暗角随环境呼吸变化。

### 🏛 展厅模式
双击进入浏览器全屏，鼠标静止 5 秒自动隐匿光标与一切控制入口——屏幕回归纯粹的内容本身。

### ⏱ 长时运行守护
内置渲染看门狗：心跳停滞 30 秒自动恢复；视频句柄随播放槽自动释放，为 7×24 小时无人值守而生。

### 🧊 玻璃拟态控制台
左侧吸附齿轮唤出毛玻璃控制台：网格、节奏、动效占比、视频开关、声音、氛围主题、展厅模式……全部实时可调，配置自动持久化。

## 🚀 快速开始

```bash
npm install
npm run dev
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:5173 |
| API | http://localhost:3001 |

打开浏览器即见媒体墙。鼠标移至屏幕左缘唤出设置齿轮；点击视频格子进入全屏播放；开启展厅模式后双击任意处全屏。

## 🏗 架构

```
├── index.html                 # Vite 入口
├── vite.config.ts             # Dev 代理（/api /uploads /ext）
├── server/                    # Express 后端
│   ├── index.ts               # 静态服务（/uploads /ext）
│   ├── storage.ts             # 媒体落盘、外部目录扫描（图 + 视频）
│   └── routes/images.ts       # 媒体列表 / 上传 / 删除
└── src/                       # React 前端
    ├── App.tsx                # 组装 + 氛围主题 + 看门狗 + 展厅模式
    ├── components/
    │   ├── Wall / WallCell    # 拼贴网格与动效单元格
    │   ├── VideoOverlay       # 全屏视频播放器
    │   ├── ControlPanel       # 玻璃拟态控制台
    │   └── ClockOverlay       # 时钟 + 天气叠加
    ├── engine/                # WallEngine 基类 + 三种换图模式
    ├── services/
    │   ├── videoCoordinator   # 视频并发播放协调器
    │   ├── theme.ts           # 时空氛围引擎
    │   ├── imagePool          # 图影混合资源池
    │   └── api / placeholder
    ├── hooks/                 # useWallConfig / useImagePool
    └── types.ts               # 全局类型与默认配置
```

**技术栈**：Vite 5 · React 18 · TypeScript 5 · Tailwind CSS · Express · multer

## ⚙️ 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `PORT` | 后端端口 | `3001` |
| `EXTERNAL_IMAGE_DIR` | 外部媒体目录（图 + 视频混合扫描） | 用户主目录「图片」文件夹 |

## 📦 媒体支持

| 类型 | 格式 | 单文件上限 |
| --- | --- | --- |
| 图片 | JPG / PNG / GIF / WebP / AVIF / BMP | 10 MB |
| 视频 | MP4 / WebM / M4V / MOV / OGV | 200 MB |

上传持久化至 `data/uploads`；外部目录只读扫描，二者自动混合轮播。

## 🍀 网络图源

可选开启 Picsum 真实网络图（默认关闭）；离线环境自动使用本地生成渐变占位，永不白屏。
